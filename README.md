# my-first-project 我的第一个GitHub项目
Vue3 + SpringBoot 前后端分离用户管理系统

## 项目结构
- `vue-user-system/`：前端Vue3项目
- `springboot-user-system/`：后端SpringBoot项目

## 技术栈
### 前端
- Vue 3 + Vite
- Element Plus（UI组件库）
- Axios（网络请求）

### 后端
- Spring Boot 3.x
- Spring Security（权限控制）
- MyBatis（持久层框架）
- MySQL（数据库）

## 运行说明
### 前端启动
```bash
cd vue-user-system
npm install
npm run dev
